# Modernize и очередь REDRAW

Modernize переносит существующую иллюстрацию в манеру [утверждённого листа](ref/modernized_sample.md). Сохраняем событие, узнаваемых героев и предметы. Меняем свет, цвет и деталировку, чтобы действие читалось в размере карты.

## Одна карта

Используй `/cardimg modernize` с названием или ID. Карта, её текст и путь к текущему арту берутся из [js/cards.js](js/cards.js). У обычного Modernize результатом первого прохода служит лист 2×2. Формулировка «один арт на карту» задаёт один самостоятельный кадр для сравнения.

Подготовь три референса в этом порядке.

1. Текущий арт карты в лёгком JPEG. Для правки уже показанного варианта первым референсом служит этот вариант. Удобно держать рабочие JPEG в отдельной папке внутри `ref/`. Большую сторону можно уменьшить до 1200 px.
2. [Лист Modernize](ref/modernized_sample.png). Однострочный блок `Style` берётся из [разбора листа](ref/modernized_sample.md).
3. [Фигуры](ref/sheet_figures.jpg), [крупные планы](ref/sheet_closeups.jpg) или [сцены](ref/sheet_scenes.jpg) по композиции. [Предметный лист](ref/sheet_objects.jpg) подходит для группы `weapon`.

В промпте перечисли детали, по которым узнаётся исходная сцена. Оставь спокойный верхний левый угол под иконки и продолжение фона в нижних 15% кадра под плашку описания. Для варианта в галерею закажи вертикальную иллюстрацию около 7:10 без текста, рамок и плашек. Для правки фона перечисли в блоке `KEEP` позу, ключевые предметы, силуэт и композицию, которые должны сохраниться.

Для одного прохода через Codex CLI используй следующий шаблон PowerShell из корня проекта. Сохрани подготовленный промпт одной строкой и подставь пути к двум рабочим файлам и подходящему третьему референсу.

```powershell
$modernizePrompt = (Get-Content -Raw -Encoding UTF8 'ref/modernize-inputs/prompt-1209.txt').Trim()
if ($modernizePrompt -match '[\r\n]') { throw 'Промпт должен быть одной строкой' }

$modernizeArgs = @(
    $modernizePrompt,
    '--name', 'modernize-1209',
    '--size', '688x976',
    '--model', 'sol',
    '--effort', 'high',
    '--timeout', '1200',
    '--ref', 'ref/modernize-inputs/original-1209.jpg',
    '--ref', 'ref/modernized_sample.png',
    '--ref', 'ref/sheet_figures.jpg'
)
py -3 "$env:USERPROFILE\.Codex\imagegen\img_gen.py" @modernizeArgs
```

Последняя строка stdout содержит путь к PNG. Проход с несколькими референсами запускай фоном.

## Случайная серия из REDRAW

Пример запроса к Codex — «Возьми 10 случайных новых карт из REDRAW, сделай по одному Modernize и собери один HTML с парами исходник и вариант».

Очередь читай перед выборкой. [list-redraw-cards.py](tools/list-redraw-cards.py) получает статус `requires_redraw` из KVDB и сверяет ID с картотекой. Скрипту нужны Python 3 и Node.js.

```powershell
$redrawCount = 10
$redrawExclude = @() # Впиши сюда ID, которые нужно пропустить в этой серии
$redrawLines = py -3 tools/list-redraw-cards.py
if ($LASTEXITCODE -ne 0) { throw 'Не удалось прочитать очередь REDRAW' }

$redrawPool = @(foreach ($redrawLine in $redrawLines) {
    if ($redrawLine -match '^#(\d+) — (.+)$') {
        $redrawId = [int]$Matches[1]
        if ($redrawId -notin $redrawExclude) {
            [pscustomobject]@{ Id = $redrawId; Title = $Matches[2] }
        }
    }
})
if ($redrawPool.Count -lt $redrawCount) {
    throw "Доступно $($redrawPool.Count) карт при запросе на $redrawCount"
}
$redrawPool | Get-Random -Count $redrawCount | Format-Table -AutoSize
```

`Get-Random` выбирает без повторов. Для запроса на ещё одну серию новых карт внеси в исключения ID из уже показанных серий и карты, для которых заказана отдельная правка. Зафиксируй список ID перед генерацией, чтобы каждому файлу соответствовала своя карта.

Запускай по одному кадру на карту, не более трёх активных проходов одновременно. Для каждой карты подбери собственный третий референс и сохрани полученный путь из stdout. Сверь сцену и детали с исходником. Для сравнения при печати можно измерить светлое поле и контраст теней с помощью [offset_check.py](.claude/skills/cardimg/offset_check.py).

Собери один HTML с названием, ID и двумя изображениями для каждой карты. Встрой изображения как data URI, чтобы сравнение открывалось без сети. Подпиши заметные изменения сцены и отклонения по печатным замерам рядом с соответствующим вариантом. Проверь открытие всех изображений в браузере.

## После выбора

После явного одобрения пользователя замени выбранные арты в картотеке и сохрани прежние PNG в `cards/obsolete/`. Добавь тег `toPrint`, обнови статичные превью карт, которые используются в правилах, и проверь новые арты через `app.html?embed=ID`. Присваивай OK в KVDB только тем картам, которые пользователь одобрил. Публикацию GitHub Pages проверяй по запуску Actions для отправленного коммита.
