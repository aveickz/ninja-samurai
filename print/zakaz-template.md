# Шаблон письма-ТЗ в типографию

Шаблон заказа печати колоды в ottisk.com — по их шаблону ТЗ из 7 пунктов.
Как собрать файлы и что проверить перед заказом — в [`printing.md`](../printing.md).
Заполнить `{…}` по выводу `tools/build-print-sheets.py`, `[…]` — вручную.
Контакты автора в репозиторий не кладём: подставить при отправке.

Числа после сборки:
- `{КАРТ}` — первое число в строке «N карт (M видов) -> …»;
- `{ВИДОВ}` — второе число в той же строке;
- `{ДАТА}` — дата в именах файлов;
- `{МБ}` — размер файла лиц.

Для русской версии карт в именах файлов `en` заменить на `ru`.
