# Авторские права и депонирование

Всё, что связано с защитой авторских прав на игру: реквизиты произведения,
состав депонируемых материалов, журнал депонирований с контрольными суммами.

## Сборка PDF для депонирования

```
py -3 tools/build-copyright-deposit.py                        # → print/copyright_deposit_<дата>.pdf
py -3 tools/build-copyright-deposit.py --list                 # разделы и что уже в кэше
py -3 tools/build-copyright-deposit.py --redo cards-ru        # перерисовать раздел, остальные из кэша
py -3 tools/build-copyright-deposit.py --redo all             # всё заново
py -3 tools/build-copyright-deposit.py --out my.pdf --quality 75
```

Разделы рендерятся по одному и лежат в кэше `print/copyright_deposit_parts/`
(в git не попадает): `rules-ru`, `cheat-ru`, `registry-ru`, `cards-ru`,
`backs`, `figures`, `rules-en`, `cheat-en`, `registry-en`, `cards-en`.
Сборка берёт готовые куски, рисует только недостающие и то, что названо в
`--redo`; титул и содержание перерисовываются всегда (секунды). Поменял
карту — `--redo cards-ru,cards-en,registry-ru,registry-en`; поправил
правила — `--redo rules-ru` и так далее. Кусок можно открыть и проверить
отдельно, не дожидаясь всей книги.

Один самодостаточный PDF, все страницы A4, сквозная нумерация в нижнем
правом углу, закладки по разделам. Порядок разделов:

1. Титульный лист — название, автор, репозиторий, дата сборки, git-коммит, состав.
2. Содержание с номерами страниц; у разделов карт — подпункты по группам.
3. Правила игры (рус.) — `rules/rules.html`, A5 → A4.
4. Памятка игрока (рус.) — `rules/cheatsheet.html`, A5 landscape → A4 landscape.
5. Реестр карт (рус.) — таблица: ID, название, типы, количество, текст
   эффекта. Из `js/cards.js`, порядок как в картотеке.
6. Карты (рус.) — печать из картотеки `app.html`, 3×3 на A4, каждая карта
   один раз (без «Печати количеством»), корзина (`trash`) не входит,
   черновики (`draft`) входят.
7. Рубашки — `media/backs/*.png`, три группы.
8. Фигурки и жетоны — превью с плиты из `3d/*.3mf`, рендеры из
   `rules/media/fig/`, тушевые иллюстрации `rules/media/fig/ink/`.
   Списков файлов в документе нет — только картинки с подписями.
9–12. То же для английской версии: `rules/rules-en.html`,
   `rules/cheatsheet-en.html`, реестр EN, `app.html?lang=en`.

Нужны: Chrome (`C:\Program Files\Google\Chrome\Application\chrome.exe`),
PyMuPDF, Pillow, node (читает `js/cards.js`), интернет — правила и
картотека тянут Google Fonts и jQuery с CDN.

Картинки пережимаются в JPEG в исходном разрешении (по умолчанию quality
85) при рендере раздела: без этого один прогон картотеки весит 200 МБ.
`--quality` действует только на перерисовываемые разделы. Арт русской и
английской версий карт — один и тот же поток в файле, дубли схлопывает
`garbage=4`.

После сборки скрипт печатает путь, число страниц, размер и SHA-256 —
строку для журнала ниже.

## Где депонировать

[nris.ru](https://nris.ru) — Национальный реестр интеллектуальной
собственности: депонирование произведения с выдачей свидетельства,
фиксирующего дату и содержимое файла. Перед загрузкой проверить текущий
лимит размера файла на сайте; если PDF не проходит — пересобрать с
`--quality 75`.

Что важно для депонирования: файл должен содержать само произведение
(правила, арт, рубашки, модели), а не ссылки на него; имя автора и
название — на титуле; контрольная сумма и коммит — в журнале ниже, чтобы
потом сопоставить свидетельство с состоянием репозитория.
